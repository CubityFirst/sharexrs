# ShareXrs

A port of [ShareX](https://github.com/ShareX/ShareX) to Rust, aiming to look
and work the same, on Windows, macOS and Linux.

**Work in progress.** Capturing, annotating, saving and uploading work;
several of ShareX's tools and editors aren't ported yet.

## Build

```
cargo build --release
```
